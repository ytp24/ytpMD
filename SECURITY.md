# Security Policy

The `ytpMD` project team takes security vulnerabilities seriously. We appreciate responsible disclosures.

---

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `3.x.x` | ✅ Full Support & Security Patches |
| `2.x.x` | ⚠️ Critical Security Fixes Only |
| `< 2.0.0` | ❌ End of Life |

---

## Reporting a Vulnerability

If you discover a security vulnerability within `ytpMD`:

1. **Do NOT open a public GitHub issue.**
2. Send a detailed report via encrypted email to:
   - **Security Contact**: `ykinwork24@gmail.com`
   - **Subject**: `[SECURITY] Vulnerability Report - ytpMD`
3. Please include:
   - Description of the vulnerability and attack vector.
   - Proof-of-concept (PoC) or reproducible steps.
   - Affected versions and environments (Linux / Windows / macOS).
   - Potential impact.

---

## Response Timeline & SLAs

- **Initial Acknowledgment**: Within 24 hours.
- **Triage & Severity Assessment**: Within 48 hours.
- **Fix & Patch Release**: Within 7 business days (or coordinated disclosure timeline).
