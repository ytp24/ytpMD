## 2. Privacy, Telemetry & Data Handling
- **100% Local-First Execution**: `ytpMD` operates entirely on your local machine.
- **Zero Telemetry**: No user analytics, metrics, usage statistics, or document contents are ever transmitted over the network.
- **Zero Cloud Dependencies**: Extraction, filtering, transformation, and storage happen strictly in offline mode without requiring network calls or third-party APIs.

---

## 3. Third-Party Dependencies & Attributions
- `ytpMD` utilizes system utilities such as `poppler-utils` (`pdftotext`, `pdfinfo`) licensed under GPLv2/GPLv3.
- `ytpMD` interacts with these external tools strictly via standard process execution boundaries without static or dynamic binary linking, maintaining complete license compliance.

## 4. Export & Regulatory Compliance
This software does not implement cryptographic encryption algorithms beyond standard operating system access libraries, and complies with international software distribution guidelines.
